async / await

async/await es azúcar sintáctica sobre las promesas: te permite escribir código asíncrono con la misma estructura plana que el código síncrono, sin .then() encadenados ni callbacks anidados.

async function

Declarar una función con async hace que automáticamente devuelva una promesa. Todo lo que retornes con return se envuelve en Promise.resolve(), y cualquier error que lances con throw se convierte en Promise.reject().

async-function.js 
async function obtenerSaludo() {
  return "Hola";
}

obtenerSaludo().then(console.log); // "Hola"

async function lanzarError() {
  throw new Error("Algo falló");
}

lanzarError().catch(console.error); // Error: Algo falló

await: esperar sin bloquear

await solo puede usarse dentro de una función async. Detiene la ejecución de esa función (sin bloquear el hilo principal) hasta que la promesa se resuelva o se rechace. El código se lee de arriba a abajo, como si fuera síncrono.

await-ejemplo.js 
function esperar(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function main() {
  console.log("Esperando…");
  await esperar(2000);
  console.log("Pasaron 2 segundos");
}

main();

try/catch con async/await

A diferencia de .catch(), con async/await puedes usar el clásico try/catch para manejar errores, exactamente igual que en código síncrono.

try-catch-async.js 
async function obtenerUsuario(id) {
  try {
    const respuesta = await fetch(`/api/usuarios/${id}`);
    if (!respuesta.ok) throw new Error("Error HTTP");
    return await respuesta.json();
  } catch (error) {
    console.error("No se pudo obtener el usuario:", error.message);
    return null;
  }
}

await Promise.all

Cuando necesitas ejecutar varias promesas en paralelo, no las hagas una tras otra con await individual — usa Promise.all combinado con await.

await-promise-all.js 
async function obtenerDashboard() {
  const [usuarios, productos, pedidos] = await Promise.all([
    fetch("/api/usuarios").then(r => r.json()),
    fetch("/api/productos").then(r => r.json()),
    fetch("/api/pedidos").then(r => r.json()),
  ]);

  return { usuarios, productos, pedidos };
}

No hagas esto: const a = await fetch(...); const b = await fetch(...); — las promesas se ejecutan en serie y pierdes tiempo. Siempre que sean independientes, lánzalas juntas con Promise.all.

Ambos enfoques son igual de válidos. async/await no reemplaza a las promesas: las usa por debajo. Elige el que te resulte más legible en cada contexto.
