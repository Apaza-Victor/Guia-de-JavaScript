Promesas

Una Promise es un objeto que representa un valor que todavía no existe, pero que existirá (o fallará) en el futuro. Son la base sobre la que se construye async/await, así que entenderlas bien te ahorra confusión más adelante.

Los tres estados de una promesa

Toda Promise nace en estado pending (pendiente) y termina en uno de estos dos:

  • fulfilled — se resolvió con éxito, tiene un valor
  • rejected — falló, tiene un motivo de error

Una vez que pasa a fulfilled o rejected, ya no cambia — se dice que está settled (resuelta, en cualquiera de los dos sentidos).

crear-promesa.js 
const promesa = new Promise((resolve, reject) => {
  const exito = true;

  setTimeout(() => {
    if (exito) {
      resolve("¡Datos listos!");
    } else {
      reject(new Error("Algo salió mal"));
    }
  }, 1000);
});

Consumir una promesa: then / catch / finally

consumir.js 
promesa
  .then(resultado => console.log(resultado))   // se ejecuta si se resuelve
  .catch(error => console.error(error.message)) // se ejecuta si falla
  .finally(() => console.log("Terminado, haya fallado o no"));

Cada .then() devuelve una nueva promesa, por eso se pueden encadenar: el valor que retornas dentro de un .then() se convierte en el valor que recibe el siguiente.

Combinar varias promesas

Cuando necesitas esperar a varias operaciones asíncronas a la vez, no las encadenes una por una — usa los métodos estáticos de Promise:

MétodoSe resuelve cuando…Falla si…
Promise.all()todas se resuelvenuna sola falla, corta todo
Promise.allSettled()todas terminan (éxito o error)nunca falla, devuelve el detalle de cada una
Promise.race()la primera en resolverse o fallarsi esa primera fue un error
promise-all.js 
const usuarios = fetch("/api/usuarios");
const productos = fetch("/api/productos");

Promise.all([usuarios, productos])
  .then(([resUsuarios, resProductos]) => {
    console.log("Ambas respuestas llegaron");
  })
  .catch(error => console.error("Alguna falló:", error));

Una promesa rechazada sin un .catch() que la maneje genera un unhandled promise rejection — en el navegador aparece como advertencia en consola, y en Node.js puede incluso terminar el proceso.
