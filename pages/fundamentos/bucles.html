Bucles: for, while, do...while, for...of y for...in

Repetir código es una de las tareas más frecuentes en programación. JavaScript ofrece varios tipos de bucles, cada uno pensado para un escenario distinto. Elegir el adecuado hace tu código más claro y menos propenso a errores.

for clásico

El bucle más tradicional. Tiene tres partes: inicialización, condición y actualización. Se usa sobre todo cuando sabes de antemano cuántas iteraciones necesitas.

for-clasico.js 
for (let i = 0; i < 5; i++) {
  console.log("Vuelta " + i);
}
// Vuelta 0, Vuelta 1, …, Vuelta 4

while

Ejecuta el bloque mientras la condición sea true. La condición se evalúa antes de cada iteración, así que puede no ejecutarse nunca si la condición inicial es falsa.

while.js 
let contador = 0;
while (contador < 3) {
  console.log(contador);
  contador++;
}
// 0, 1, 2

do...while

Similar a while, pero la condición se evalúa después de ejecutar el bloque. Esto garantiza que el código se ejecute al menos una vez.

do-while.js 
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 3);
// 0, 1, 2

for...of

Itera sobre valores de objetos iterables como arrays, strings, Map o Set. Es la forma más limpia de recorrer un array cuando no necesitas el índice.

for-of.js 
let frutas = ["manzana", "banana", "cereza"];
for (let fruta of frutas) {
  console.log(fruta);
}
// "manzana", "banana", "cereza"

for...in

Itera sobre las claves (propiedades) de un objeto. No lo uses con arrays: aunque funciona, itera sobre los índices como strings y puede incluir propiedades heredadas.

for-in.js 
let usuario = { nombre: "Ana", edad: 28, rol: "admin" };
for (let clave in usuario) {
  console.log(clave + ": " + usuario[clave]);
}
// "nombre: Ana", "edad: 28", "rol: admin"

No uses for...in para arrays: recorre los índices como strings ("0", "1", …) y puede traer propiedades del prototipo. Para arrays usa for...of o los métodos como forEach.

break y continue

break sale del bucle por completo. continue salta a la siguiente iteración sin ejecutar el resto del bloque.

break-continue.js 
for (let i = 0; i < 10; i++) {
  if (i === 5) break;      // termina el bucle en 5
  if (i % 2 === 0) continue; // salta pares
  console.log(i);
}
// 1, 3
