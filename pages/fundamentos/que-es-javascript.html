¿Qué es JavaScript?

JavaScript es el lenguaje que hace que una página web reaccione: valide un formulario, mueva un menú, actualice datos sin recargar. Nació para el navegador, pero hoy corre casi en cualquier lugar.

Un poco de historia

JavaScript fue creado en 1995 por Brendan Eich en 10 días, para darle interactividad al navegador Netscape. A pesar del nombre, no tiene relación directa con Java — el nombre fue una decisión de marketing de la época. Desde entonces se estandarizó bajo el nombre ECMAScript, y cada versión anual (ES2015, ES2016...) agrega nuevas funcionalidades al lenguaje.

¿Dónde se ejecuta?

Originalmente solo en el navegador, pero hoy JavaScript corre en varios entornos:

  • Navegador — Chrome, Firefox, Safari, cada uno con su propio motor
  • Servidor — con Node.js, fuera del navegador
  • Apps móviles y de escritorio — con frameworks como React Native o Electron

El motor V8

Un motor de JavaScript es el programa que lee tu código y lo ejecuta. V8 es el motor de Google, usado en Chrome y en Node.js. Su trabajo, resumido, es:

  1. Parsear el código (convertirlo en una estructura que la máquina entiende)
  2. Compilarlo a código máquina en tiempo real (JIT — Just In Time)
  3. Ejecutarlo y optimizarlo mientras corre
hola-mundo.js 
console.log("Hola, motor V8");
// Esto se ejecuta igual en un navegador que en Node.js

No necesitas entender cómo funciona V8 por dentro para programar bien en JS — pero saber que existe te ayuda a entender por qué el mismo código puede comportarse igual en el navegador y en un servidor Node.js.
