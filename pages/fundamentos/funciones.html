Funciones: declaración, expresión y arrow functions

Las funciones son el centro de la reutilización en JavaScript. No solo agrupan lógica, sino que también definen scope y se comportan de forma distinta según cómo las declares.

function declaration

La forma clásica de declarar una función. Una característica clave: estas funciones sufren hoisting completo, lo que significa que puedes llamarlas antes de declararlas en el código.

declaration.js 
saludar("Ana"); // ✅ funciona por hoisting

function saludar(nombre) {
  return "Hola, " + nombre;
}

console.log(saludar("Ana")); // "Hola, Ana"

function expression

Asignas una función a una variable. Aquí no hay hoisting del valor: la variable se declara pero no se asigna hasta la línea donde se define.

expression.js 
console.log(sumar(2, 3)); // ❌ ReferenceError: cannot access before initialization

const sumar = function (a, b) {
  return a + b;
};

console.log(sumar(2, 3)); // 5

Arrow functions

Introducidas en ES6, tienen sintaxis más corta y no crean su propio this —heredan el del contexto donde se definen. Ideales para callbacks y métodos funcionales.

arrow.js 
// Forma explícita (con return)
const multiplicar = (a, b) => {
  return a * b;
};

// Forma compacta (return implícito)
const multiplicarCompacto = (a, b) => a * b;

console.log(multiplicar(4, 3));      // 12
console.log(multiplicarCompacto(4, 3)); // 12

// Un solo parámetro: paréntesis opcionales
const cuadrado = x => x ** 2;
console.log(cuadrado(5)); // 25

Return implícito: cuando el cuerpo de una arrow function es una sola expresión sin llaves, esa expresión se devuelve automáticamente. Para devolver un objeto literal, envuélvelo entre paréntesis: () => ({ clave: "valor" }).

Parámetros

JavaScript permite valores por defecto para parámetros y el operador rest para capturar argumentos sobrantes en un array.

parametros.js 
// Parámetro por defecto
function saludar(nombre = "visitante") {
  return "Hola, " + nombre;
}
console.log(saludar());         // "Hola, visitante"
console.log(saludar("Ana"));    // "Hola, Ana"

// Rest operator
function sumarTodos(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}
console.log(sumarTodos(1, 2, 3, 4)); // 10
