Tipos de datos: primitivos vs referencia

Todo valor en JavaScript pertenece a un tipo, y ese tipo determina cómo se copia, se compara y se guarda en memoria. Confundir un tipo primitivo con uno de referencia es una de las fuentes más comunes de bugs para quien empieza.

Tipos primitivos

Son 7, y se copian por valor: cuando asignas uno a otra variable, se duplica el valor completo.

  • string — texto: "hola"
  • number — números (enteros y decimales): 42, 3.14
  • boolean — true / false
  • undefined — variable declarada sin valor asignado
  • null — ausencia de valor, asignada intencionalmente
  • bigint — enteros arbitrariamente grandes: 123n
  • symbol — identificador único e inmutable
primitivos.js 
let a = 10;
let b = a; // se copia el VALOR
b = 20;

console.log(a); // 10 — a no cambió

Tipos de referencia

Objetos, arrays y funciones se copian por referencia: la variable no guarda el valor, guarda una dirección hacia donde vive ese valor en memoria.

referencia.js 
let obj1 = { valor: 10 };
let obj2 = obj1; // se copia la REFERENCIA
obj2.valor = 20;

console.log(obj1.valor); // 20 — ¡ambas apuntan al mismo objeto!

Por esto, comparar dos objetos con === compara si son la misma referencia, no si tienen el mismo contenido: {a:1} === {a:1} da false.

Detectar el tipo con typeof

typeof.js 
typeof "hola";      // "string"
typeof 42;           // "number"
typeof true;         // "boolean"
typeof undefined;    // "undefined"
typeof null;         // "object" — famoso bug histórico del lenguaje
typeof [1, 2, 3];    // "object" — los arrays son objetos
typeof function(){}; // "function"
