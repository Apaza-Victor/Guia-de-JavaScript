Operadores: aritméticos, comparación, lógicos y ternario

Los operadores son los bloques con los que construyes lógica: desde sumar dos números hasta decidir qué bloque de código ejecutar. JavaScript tiene varios tipos, y cada uno tiene matices que vale la pena conocer.

Operadores aritméticos

Sirven para realizar operaciones matemáticas. Los mismos de siempre, más el módulo (%) que da el resto de una división, y la exponenciación (**) introducida en ES2016.

aritmeticos.js 
let suma = 10 + 5;       // 15
let resta = 10 - 5;      // 5
let multi = 10 * 5;      // 50
let div = 10 / 3;        // 3.333...
let modulo = 10 % 3;     // 1 — resto de 10 ÷ 3
let expo = 2 ** 4;       // 16 — 2 elevado a 4

console.log(suma, resta, multi, div, modulo, expo);

Módulo no es solo para números pares: también se usa para ciclar índices, convertir unidades o validar rangos. Por ejemplo, i % 2 === 0 detecta pares, pero i % 4 te da ciclos de 4.

Operadores de comparación

Comparan dos valores y devuelven un booleano. La gran trampa: == vs ===. El primero permite coerción de tipos (ver tema siguiente), el segundo es estricto y siempre deberías preferirlo.

comparacion.js 
console.log(5 == "5");   // true  (coerción: string → number)
console.log(5 === "5");  // false (tipos distintos)

console.log(5 != "5");   // false (coerción)
console.log(5 !== "5");  // true  (tipos distintos)

console.log(10 > 5);     // true
console.log(10 < 5);     // false
console.log(10 >= 10);   // true
console.log(10 <= 5);    // false

Operadores lógicos

Combinan expresiones booleanas. && (AND) devuelve true solo si ambos operandos son truthy. || (OR) devuelve true si al menos uno lo es. ! (NOT) niega el valor.

logicos.js 
let edad = 22;
let tieneCarnet = true;

// AND — ambas condiciones deben cumplirse
console.log(edad >= 18 && tieneCarnet); // true

// OR — basta con una
console.log(edad >= 18 || tieneCarnet); // true

// NOT
console.log(!tieneCarnet); // false

Short-circuit evaluation: && y || no siempre devuelven un booleano. Evalúan de izquierda a derecha y devuelven el primer valor que determina el resultado. Por ejemplo, "A" || "B" devuelve "A" porque es truthy y corta la evaluación.

Operador ternario

Es una forma compacta de escribir un if/else simple. Sintaxis: condición ? valor_si_true : valor_si_false.

ternario.js 
let edad = 20;
let mensaje = edad >= 18 ? "Eres mayor de edad" : "Eres menor";
console.log(mensaje); // "Eres mayor de edad"

Úsalo con mesura. El ternario es ideal para asignaciones rápidas. Si la lógica se complica (ternarios anidados), mejor usa if/else tradicional: tu código se lee de arriba abajo, no en diagonal.
