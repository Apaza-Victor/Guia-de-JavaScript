Cómo enlazar JS en HTML

La etiqueta <script> parece trivial, pero dónde la pones y qué atributo le agregas cambia por completo cuándo y cómo se ejecuta tu código — y puede ser la diferencia entre una página rápida y una que se traba al cargar.

La forma básica

Puedes incluir JavaScript directo en el HTML o —mejor práctica— en un archivo aparte:

index.html 
<!-- Código inline: evitar en proyectos reales -->
<script>
  console.log("inline");
</script>

<!-- Archivo externo: la forma correcta -->
<script src="app.js"></script>

El problema de un script normal

Por defecto, cuando el navegador encuentra un <script>, detiene todo para descargarlo y ejecutarlo antes de seguir construyendo la página. Si lo pones en el <head>, el usuario ve una pantalla en blanco más tiempo.

defer vs async

Ambos atributos descargan el script en paralelo sin bloquear el renderizado, pero cambian cuándo se ejecuta:

AtributoDescargaEjecuciónOrden garantizado
(ninguno)bloquea el parseoinmediatasí
deferen paraleloal terminar de parsear el HTMLsí
asyncen paraleloapenas termina de descargarno
index.html 
<script src="app.js" defer></script>
<script src="analytics.js" async></script>

Regla práctica: usa defer para tu código de aplicación (necesita el DOM completo y el orden importa) y async solo para scripts independientes como analíticas, que no dependen de nada más.
