Variables: var, let y const

Antes de escribir cualquier lógica, JavaScript necesita un lugar donde guardar valores. Estas tres palabras clave hacen exactamente eso, pero con reglas de alcance y reasignación muy distintas — y elegir mal puede causar bugs difíciles de rastrear.

¿Qué es una variable?

Una variable es un espacio con nombre donde guardas un valor para usarlo más adelante. En JavaScript se declaran con var, let o const, y la diferencia entre ellas no es solo de sintaxis: cambia dónde existen (scope) y si pueden reasignarse.

ejemplo.js 
let nombre = "Ana";
const edad = 28;
var activo = true;

console.log(nombre, edad, activo);
// "Ana" 28 true

const: no se reasigna

const crea una referencia constante. No puedes reasignarla, pero si guarda un objeto o array, su contenido sí puede cambiar — lo que es constante es la referencia, no el valor interno.

const-no-es-inmutable.js 
const usuario = { nombre: "Ana" };
usuario.nombre = "Lucía"; // ✅ funciona: modificas el contenido
console.log(usuario); // { nombre: "Lucía" }

usuario = {}; // ❌ TypeError: Assignment to constant variable.

Regla práctica: usa const por defecto. Solo cambia a let cuando sepas que vas a reasignar el valor (un contador, un acumulador, etc.).

let: variables con scope de bloque

let sí permite reasignación, y —al igual que const— vive únicamente dentro del bloque { } donde se declaró.

scope-de-bloque.js 
if (true) {
  let mensaje = "hola";
  console.log(mensaje); // "hola"
}

console.log(mensaje); // ❌ ReferenceError: mensaje is not defined

var: la forma antigua (y por qué evitarla)

var existe desde el JavaScript original. Su scope es de función, no de bloque, lo que provoca comportamientos poco intuitivos como este:

problema-de-var.js 
if (true) {
  var mensaje = "hola";
}

console.log(mensaje); // "hola" — ¡se filtró fuera del bloque!

for (var i = 0; i < 3; i++) {}
console.log(i); // 3 — var "sobrevive" al bucle

var también sufre hoisting con valor inicial undefined, lo que permite usarla antes de declararla sin error visible. Por eso en código moderno casi nunca se usa var.
