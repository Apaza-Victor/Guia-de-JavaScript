Spread / Rest operator (...)

El operador ... tiene dos caras: como spread expande elementos; como rest los agrupa. Aunque la sintaxis es la misma, el contexto determina su comportamiento.

Spread en arrays

El spread ... expande los elementos de un array en lugares donde se esperan múltiples valores, como dentro de otro array o como argumentos de una función.

spread-array.js 
const frutas = ["manzana", "pera"];
const mas = ["uva", ...frutas, "naranja"];
console.log(mas); // ["uva", "manzana", "pera", "naranja"]

// Clonar array
const copia = [...frutas];

// Convertir string a array
console.log([..."hola"]); // ["h", "o", "l", "a"]

Spread en objetos

Permite copiar propiedades de un objeto dentro de otro. El orden importa: las propiedades posteriores sobrescriben a las anteriores si hay conflicto de clave.

spread-objeto.js 
const base = { nombre: "Ana", edad: 28 };
const extras = { edad: 30, ciudad: "Madrid" };

const usuario = { ...base, ...extras };
console.log(usuario);
// { nombre: "Ana", edad: 30, ciudad: "Madrid" }

El spread en objetos hace copia superficial (shallow copy). Si una propiedad es otro objeto, ambos comparten la misma referencia.

Rest parameters

Cuando ... aparece en la definición de una función, agrupa los argumentos restantes en un array. Es la forma moderna de manejar número variable de argumentos.

rest-params.js 
function sumar(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}

console.log(sumar(1, 2, 3));    // 6
console.log(sumar(10, 20, 30, 40)); // 100

// Rest después de parámetros fijos
function listar(prefijo, ...items) {
  return items.map(i => `${prefijo}: ${i}`);
}

Rest en destructuring

Puedes usar rest para agrupar los elementos o propiedades sobrantes al hacer destructuring.

rest-destructuring.js 
// Con arrays
const [primero, ...resto] = [1, 2, 3, 4];
console.log(primero); // 1
console.log(resto);   // [2, 3, 4]

// Con objetos
const { nombre, ...datos } = { nombre: "Ana", edad: 28, ciudad: "Madrid" };
console.log(nombre); // "Ana"
console.log(datos);  // { edad: 28, ciudad: "Madrid" }

Comparación: Spread vs Rest

ContextoRolEjemplo
En array literal / llamada funciónSpread — expande[...arr] / Math.max(...nums)
En objeto literalSpread — copia propiedades{...obj}
En parámetro de funciónRest — agrupa argumentosfunction f(...args)
En destructuringRest — agrupa resto[a, ...b] = arr

La regla mental: spread ocurre en el lado derecho (construcción/expansión), rest en el lado izquierdo (declaración/destructuring).
