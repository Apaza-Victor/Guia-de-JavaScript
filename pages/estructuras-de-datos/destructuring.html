Destructuring

El destructuring permite extraer valores de arrays y objetos en variables individuales con una sintaxis declarativa que hace el código más limpio y expresivo.

Destructuring de arrays

La sintaxis usa corchetes en el lado izquierdo de la asignación para desempaquetar elementos según su posición.

destructuring-array.js 
const colores = ["rojo", "verde", "azul"];

const [primero, segundo, tercero] = colores;
console.log(primero); // "rojo"
console.log(segundo); // "verde"

// Saltar elementos
const [rojo, , azul] = colores;
console.log(azul); // "azul"

Destructuring de objetos

Con objetos se usan llaves y las variables deben coincidir con el nombre de la propiedad.

destructuring-objeto.js 
const usuario = { nombre: "Ana", edad: 28, ciudad: "Madrid" };

const { nombre, edad } = usuario;
console.log(nombre); // "Ana"
console.log(edad);   // 28

Valores por defecto

Si el valor extraído es undefined, puedes asignar un valor por defecto.

valores-por-defecto.js 
const usuario = { nombre: "Ana" };
const { nombre, edad = 18 } = usuario;
console.log(edad); // 18

const [a = 1, b = 2] = [10];
console.log(a); // 10
console.log(b); // 2

Renombrado

Puedes asignar un nombre de variable distinto al de la propiedad con la sintaxis propiedad: nuevoNombre.

renombrado.js 
const usuario = { nombre: "Ana", edad: 28 };

const { nombre: userName, edad: userAge } = usuario;
console.log(userName); // "Ana"
console.log(userAge);  // 28

Destructuring anidado

Funciona en profundidad: puedes extraer propiedades de objetos dentro de objetos o arrays dentro de arrays.

anidado.js 
const persona = {
  nombre: "Carlos",
  direccion: {
    ciudad: "Barcelona",
    codigo: "08001"
  },
  hobbies: ["leer", "correr"]
};

const { direccion: { ciudad }, hobbies: [primero] } = persona;
console.log(ciudad); // "Barcelona"
console.log(primero); // "leer"

En parámetros de función

Es muy común destructurear directamente en los parámetros, sobre todo con objetos de configuración.

parametros.js 
function saludar({ nombre, edad }) {
  return `Hola, soy ${nombre} y tengo ${edad} años.`;
}

const usuario = { nombre: "Ana", edad: 28, ciudad: "Madrid" };
console.log(saludar(usuario)); // "Hola, soy Ana y tengo 28 años."

Usa destructuring en parámetros para que las funciones dejen claro qué propiedades esperan del objeto recibido. También es ideal para trabajar con APIs que devuelven objetos grandes.
