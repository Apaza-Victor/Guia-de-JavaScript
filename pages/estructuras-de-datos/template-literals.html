Template literals

Las plantillas de cadena (template literals) llegaron con ES6 para acabar con las concatenaciones tediosas. Permiten interpolación, saltos de línea sin escapes y hasta lógica personalizada con tagged templates.

String interpolation con ${}

Los template literals se delimitan con comillas invertidas (backticks `) y permiten incrustar cualquier expresión JavaScript con la sintaxis ${…}.

interpolacion.js 
const nombre = "Ana";
const edad = 28;

// Concatenación clásica (evitar)
const msg1 = "Hola, me llamo " + nombre + " y tengo " + edad + " años.";

// Template literal
const msg2 = `Hola, me llamo ${nombre} y tengo ${edad} años.`;

console.log(msg2);
// "Hola, me llamo Ana y tengo 28 años."

Dentro de ${} puedes poner cualquier expresión: operaciones aritméticas, llamadas a funciones, ternarios, etc.

expresiones.js 
const a = 10;
const b = 3;

console.log(`${a} + ${b} = ${a + b}`);     // "10 + 3 = 13"
console.log(`${a} es ${a > b ? "mayor" : "menor"} que ${b}`);
// "10 es mayor que 3"

Multi-line strings

Con template literals puedes escribir cadenas con saltos de línea reales sin necesidad de \n. El string respeta los saltos que escribas.

multi-linea.js 
const poema = `
  Rómpase o no el alma
  al fin, la claridad
  entra por los resquicios
  de lo que no entendí.
`;

console.log(poema);

Tagged templates

Una tagged template es una función que recibe el array de partes literales y los valores interpolados, y devuelve el string procesado. Es útil para sanitización, internacionalización o crear DSLs.

tagged.js 
function resaltar(strings, ...valores) {
  return strings.reduce((acc, str, i) =>
    `${acc}${str}${valores[i] || ""}`, ""
  );
}

const usuario = "Ana";
const accion = "logueó";

const resultado = resaltar`El usuario ${usuario} se ${accion} correctamente.`;
console.log(resultado);
// "El usuario Ana se logueó correctamente."

Los template literals mejoran la legibilidad frente a la concatenación con +. Como regla general, si necesitas construir una cadena con variables, usa siempre backticks.
