Map, Set, WeakMap, WeakSet

Los objetos y arrays no siempre son la mejor opción. Map y Set llegaron en ES6 para cubrir casos concretos —colecciones con claves de cualquier tipo y listas sin duplicados— mientras que sus variantes "débiles" ayudan con la gestión de memoria.

Map

Un Map es una colección de pares clave-valor donde la clave puede ser cualquier tipo (objetos, funciones, NaN). A diferencia de un objeto literal, un Map recuerda el orden de inserción y tiene un tamaño conocible al instante.

map.js 
const usuarios = new Map();

usuarios.set("ana", { edad: 28 });
usuarios.set("carlos", { edad: 30 });

console.log(usuarios.get("ana"));     // { edad: 28 }
console.log(usuarios.has("carlos"));  // true
usuarios.delete("ana");
console.log(usuarios.size);           // 1

// Claves de cualquier tipo
const objKey = { id: 1 };
usuarios.set(objKey, "valor con clave objeto");
console.log(usuarios.get(objKey));

Set

Un Set es una colección de valores únicos. Cada valor solo puede aparecer una vez, lo que lo hace ideal para eliminar duplicados o llevar un registro de elementos visitados.

set.js 
const numeros = new Set([1, 2, 3, 3, 4, 4, 4]);
console.log(numeros); // Set { 1, 2, 3, 4 }
console.log(numeros.size); // 4

numeros.add(5);
console.log(numeros.has(2)); // true
numeros.delete(1);

// Eliminar duplicados de un array
const conRepes = [1, 2, 2, 3, 3, 3];
const unicos = [...new Set(conRepes)];
console.log(unicos); // [1, 2, 3]

WeakMap y WeakSet

Son versiones "débiles" de Map y Set. La diferencia clave es que no impiden que el garbage collector elimine las referencias a sus claves (WeakMap) o valores (WeakSet). Se usan para asociar metadatos a objetos sin evitar que se limpien cuando ya no se necesitan.

WeakMap y WeakSet solo aceptan objetos como claves/valores, no tienen .size, y no son iterables. No puedes recorrerlos ni saber cuántos elementos contienen, porque esa información quedaría obsoleta en cuanto el GC actuara.

weakmap.js 
let elemento = document.querySelector(".mi-clase");
const metadata = new WeakMap();

metadata.set(elemento, { visitado: true });

// Cuando elemento se elimina del DOM y pierde todas las referencias,
// el GC limpia tanto el nodo como su entrada en metadata.
elemento = null; // ahora metadata también libera la memoria

Usa Map cuando necesites claves que no sean strings (objetos, números como claves significativas) o cuando agregues/elimines pares con frecuencia. Usa Set para asegurar unicidad. Para el resto, objeto literal o array siguen siendo la opción más simple y rápida.
