Objetos literales

Los objetos son el mecanismo principal de JavaScript para agrupar datos relacionados. Con la sintaxis literal puedes crear desde una simple configuración hasta modelos de datos complejos sin necesidad de clases.

Sintaxis de objeto literal

Un objeto literal se define con llaves { } y contiene pares clave-valor. Las claves pueden ser cadenas o símbolos; los valores pueden ser cualquier tipo, incluyendo otros objetos y funciones.

objeto-literal.js 
const usuario = {
  nombre: "Ana",
  edad: 28,
  activo: true,
  direccion: {
    ciudad: "Madrid",
    codigoPostal: "28001"
  },
  saludar: function () {
    return `Hola, soy ${this.nombre}`;
  }
};

Acceso a propiedades: dot vs bracket

Hay dos formas de acceder a una propiedad. punto es más legible, pero el corchete permite usar variables y claves con caracteres especiales.

acceso.js 
const usuario = { nombre: "Ana", "edad-persona": 28 };

console.log(usuario.nombre);        // "Ana"
console.log(usuario["edad-persona"]); // 28

const clave = "nombre";
console.log(usuario[clave]);        // "Ana" — acceso dinámico

Property shorthand

Cuando el nombre de la variable coincide con la clave que quieres usar, puedes omitir el valor y escribir solo la clave. Es azúcar sintáctico muy usado en la práctica.

shorthand.js 
const nombre = "Carlos";
const edad = 30;

// Sin shorthand
const a = { nombre: nombre, edad: edad };

// Con shorthand
const b = { nombre, edad };

console.log(b); // { nombre: "Carlos", edad: 30 }

Computed properties

Puedes usar una expresión entre corchetes como nombre de clave en la definición del objeto. Esto se llama computed property.

computed.js 
const prefijo = "user_";
const id = 42;

const usuario = {
  [prefijo + id]: "activo",
  [`${prefijo}rol`]: "admin"
};

console.log(usuario); // { user_42: "activo", user_rol: "admin" }

Recorrer objetos: Object.keys, Object.values, Object.entries

Estos métodos estáticos devuelven arrays con las claves, valores o pares clave-valor del objeto, respectivamente. Son la forma limpia de iterar sobre objetos.

object-keys-values.js 
const producto = { nombre: "Laptop", precio: 1200, stock: 5 };

console.log(Object.keys(producto));
// ["nombre", "precio", "stock"]

console.log(Object.values(producto));
// ["Laptop", 1200, 5]

console.log(Object.entries(producto));
// [["nombre", "Laptop"], ["precio", 1200], ["stock", 5]]

Object.assign

Copia las propiedades de uno o más objetos fuente a un objeto destino. Se usa para combinar objetos o clonar superficialmente.

object-assign.js 
const defaults = { modo: "claro", idioma: "es" };
const usuario = { idioma: "en" };

const config = Object.assign({}, defaults, usuario);
console.log(config); // { modo: "claro", idioma: "en" }

Object.assign hace copia superficial. Para objetos anidados, considera structuredClone o spread operator con objetos (lo veremos en Spread / Rest).
