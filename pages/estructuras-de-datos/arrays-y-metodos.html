Arrays y métodos: map, filter, reduce, forEach, find, sort

Los arrays son la estructura de datos más usada en JavaScript. Saber transformarlos con los métodos adecuados marca la diferencia entre código declarativo legible y bucles manuales difíciles de mantener.

Crear arrays

Un array en JavaScript es una lista ordenada de elementos. Puedes crearlo con la sintaxis literal —la recomendada— o con el constructor new Array().

crear-arrays.js 
// Literal (recomendado)
const frutas = ["manzana", "plátano", "naranja"];

// Constructor (evitar)
const numeros = new Array(1, 2, 3);

const vacio = [];
console.log(vacio.length); // 0

Métodos mutables (modifican el array original)

Estos métodos alteran el array sobre el que se invocan. Son útiles para operaciones rápidas, pero pueden generar efectos secundarios si no se tiene cuidado.

mutables.js 
const arr = [1, 2, 3];

arr.push(4);     // [1, 2, 3, 4]  — añade al final
arr.pop();        // [1, 2, 3]     — elimina el último
arr.shift();      // [2, 3]        — elimina el primero
arr.unshift(0);   // [0, 2, 3]     — añade al inicio
arr.splice(1, 1); // [0, 3]        — elimina 1 elemento en índice 1

Métodos inmutables (devuelven un nuevo array)

Estos métodos no modifican el array original, sino que devuelven uno nuevo. Son la base del estilo declarativo y funcional en JavaScript.

forEach

Itera sobre cada elemento. No devuelve nada, solo ejecuta un efecto secundario.

forEach.js 
const numeros = [1, 2, 3];
numeros.forEach(n => console.log(n * 2));
// 2, 4, 6

map

Transforma cada elemento y devuelve un array del mismo tamaño.

map.js 
const dobles = [1, 2, 3].map(n => n * 2);
console.log(dobles); // [2, 4, 6]

filter

Filtra elementos según una condición. Devuelve un array con los que la cumplen.

filter.js 
const pares = [1, 2, 3, 4, 5].filter(n => n % 2 === 0);
console.log(pares); // [2, 4]

reduce

Acumula los elementos en un solo valor. Es el más potente y el que más cuesta al principio.

reduce.js 
const suma = [1, 2, 3, 4].reduce((acc, n) => acc + n, 0);
console.log(suma); // 10

find

Devuelve el primer elemento que cumple la condición, o undefined si ninguno la cumple.

find.js 
const primerMayor = [1, 4, 2, 7].find(n => n > 5);
console.log(primerMayor); // 7

some y every

some comprueba si al menos un elemento cumple la condición. every comprueba si todos la cumplen.

some-every.js 
const nums = [1, 2, 3, 4];
console.log(nums.some(n => n > 3));  // true
console.log(nums.every(n => n > 0)); // true
console.log(nums.every(n => n > 2)); // false

sort

Ordena el array. Atención: por defecto convierte a string y ordena alfabéticamente. Siempre pasa una función comparadora.

sort.js 
const nums = [3, 20, 1];
nums.sort();               // [1, 20, 3] — orden alfabético 😱
nums.sort((a, b) => a - b); // [1, 3, 20] — numérico ascendente

Spread con arrays

El operador ... permite expandir los elementos de un array en lugares donde se esperan múltiples valores.

spread-array.js 
const a = [1, 2, 3];
const b = [4, 5, 6];
const combinado = [...a, ...b]; // [1, 2, 3, 4, 5, 6]

const clon = [...a]; // copia superficial

Prefiere métodos inmutables siempre que puedas: el código es más predecible y fácil de depurar. Reserva push y splice para cuando trabajes con arrays muy grandes y necesites rendimiento.
