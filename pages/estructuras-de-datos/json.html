JSON: parse / stringify

JSON es el formato de intercambio de datos más usado en la web. JavaScript lo integra de forma nativa con dos funciones: JSON.parse para leer y JSON.stringify para escribir.

¿Qué es JSON?

JSON (JavaScript Object Notation) es un formato de texto ligero para almacenar y transportar datos. Aunque su sintaxis se parece a la de un objeto literal de JavaScript, tiene reglas más estrictas: las claves deben ir entre comillas dobles, no admite funciones ni undefined, y los strings se delimitan siempre con ".

JSON.parse()

Convierte una cadena JSON en un valor de JavaScript (objeto, array, string, número, booleano o null).

json-parse.js 
const json = '{"nombre":"Ana","edad":28,"activo":true}';
const usuario = JSON.parse(json);

console.log(usuario.nombre); // "Ana"
console.log(usuario.edad);   // 28

JSON.parse acepta un segundo parámetro opcional, un reviver que transforma cada valor antes de devolverlo.

reviver.js 
const json = '{"anio":2024,"mes":12}';
const fecha = JSON.parse(json, (clave, valor) =>
  clave === "anio" ? valor + 1 : valor
);
console.log(fecha.anio); // 2025

JSON.stringify()

Convierte un valor de JavaScript en una cadena JSON. Es lo que usas para enviar datos a un servidor o guardarlos en localStorage.

json-stringify.js 
const usuario = { nombre: "Ana", edad: 28, activo: true };
const json = JSON.stringify(usuario);
console.log(json);
// '{"nombre":"Ana","edad":28,"activo":true}'

Pretty-print con espacio

El tercer parámetro de stringify controla la indentación del resultado. Muy útil para depuración o logs.

pretty-print.js 
const usuario = { nombre: "Ana", edad: 28, direccion: { ciudad: "Madrid" } };
console.log(JSON.stringify(usuario, null, 2));
// {
//   "nombre": "Ana",
//   "edad": 28,
//   "direccion": {
//     "ciudad": "Madrid"
//   }
// }

Referencias circulares: si el objeto tiene una referencia que apunta a sí mismo (directa o indirectamente), JSON.stringify lanza un error TypeError: Converting circular structure to JSON. En esos casos necesitas una librería especializada o reemplazar la referencia con null mediante el segundo parámetro (replacer).
