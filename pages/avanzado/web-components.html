Web Components

Los Web Components son un conjunto de tecnologías nativas del navegador que permiten crear componentes reutilizables sin frameworks. Custom Elements, Shadow DOM y HTML Templates forman el estándar.

Custom Elements

Un Custom Element es una etiqueta HTML personalizada. Se define creando una clase que extiende HTMLElement y registrándola con customElements.define. Su nombre debe llevar un guion medio (kebab-case) para diferenciarlo de los elementos nativos.

custom-element.js 
class SaludoCard extends HTMLElement {
  constructor() {
    super();
    this.innerHTML = `
      

        
${this.getAttribute('nombre') || 'Invitado'}

        
${this.getAttribute('mensaje') || 'Bienvenido'}

      

    `;
  }
}
customElements.define('saludo-card', SaludoCard);

Uso en HTML:

index.html 
<saludo-card nombre="Ana" mensaje="Bienvenida al curso"></saludo-card>

Lifecycle callbacks

El navegador invoca métodos automáticos durante el ciclo de vida del elemento:

  • connectedCallback — cuando se inserta en el DOM
  • disconnectedCallback — cuando se elimina del DOM
  • attributeChangedCallback — cuando cambia un atributo observado
  • observedAttributes — array estático con los atributos a observar
lifecycle.js 
class MiElemento extends HTMLElement {
  static get observedAttributes() {
    return ['estado'];
  }

  connectedCallback() {
    console.log('Conectado al DOM');
    this.actualizar();
  }

  attributeChangedCallback(nombre, viejo, nuevo) {
    if (viejo !== nuevo) this.actualizar();
  }

  actualizar() {
    this.textContent = `Estado: ${this.getAttribute('estado')}`;
  }
}

customElements.define('mi-elemento', MiElemento);

Shadow DOM

El Shadow DOM proporciona encapsulación: el CSS y el DOM del componente quedan aislados del resto de la página. No hay fugas de estilos ni conflictos con selectores externos.

shadow-dom.js 
class Tooltip extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = `
      
      
      ${this.getAttribute('texto')}
    `;
  }
}
customElements.define('mi-tooltip', Tooltip);

Shadow DOM y estilos. El CSS dentro del Shadow DOM no afecta al exterior y viceversa. Si necesitas que estilos globales penetren el shadow, usa CSS ::part() o ::slotted().

HTML Templates

La etiqueta <template> guarda HTML que no se renderiza hasta que se clona e inserta. Es ideal para definir la estructura de un componente sin que se vea en la página.

template.html 
<template id="card-template">
  <style>
    .card { border: 1px solid #ccc; padding: 1rem; }
    .card h3 { margin: 0 0 0.5rem; }
  </style>
  <div class="card">
    <h3></h3>
    <p><slot></slot></p>
  </div>
</template>
template.js 
const template = document.getElementById('card-template');
const clone = template.content.cloneNode(true);
clone.querySelector('h3').textContent = 'Título';
document.body.appendChild(clone);
