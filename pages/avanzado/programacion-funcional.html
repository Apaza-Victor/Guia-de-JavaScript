Programación funcional

La programación funcional no es una moda: es una forma de escribir código más predecible y testeable. JavaScript permite adoptar sus principios sin necesidad de un lenguaje funcional puro.

Funciones puras

Una función pura devuelve el mismo resultado para los mismos argumentos y no produce efectos secundarios (side effects). No modifica variables externas, no hace llamadas a APIs ni escribe en consola.

pura-vs-impura.js 
// Pura
function suma(a, b) {
  return a + b;
}

// Impura (modifica un estado externo)
let total = 0;
function agregarAlTotal(valor) {
  total += valor;
}

Inmutabilidad

Trabajar con datos inmutables significa que nunca modificas un objeto o array existente: creas uno nuevo con los cambios aplicados. JavaScript no fuerza inmutabilidad, pero puedes practicarla con Object.freeze, spread operator y librerías como Immer.

inmutabilidad.js 
const usuario = { nombre: 'Ana', edad: 30 };

// Mutación (mal)
usuario.edad = 31;

// Inmutable (bien)
const usuarioActualizado = { ...usuario, edad: 31 };

console.log(usuario.edad);           // 30 (original intacto)
console.log(usuarioActualizado.edad); // 31

Cuidado con la mutación accidental. Métodos como Array.prototype.sort mutan el array original. Haz una copia antes: [...arr].sort().

Composición de funciones

Componer funciones es combinar funciones simples para crear operaciones más complejas. Cada función toma la salida de la anterior.

composicion.js 
const doblar = n => n * 2;
const sumarUno = n => n + 1;

const componer = (f, g) => x => f(g(x));

const doblarYSumar = componer(sumarUno, doblar);
console.log(doblarYSumar(5)); // 11 (5*2=10, 10+1=11)

Currying

El currying transforma una función de múltiples argumentos en una secuencia de funciones que toman un solo argumento cada una.

currying.js 
const multiplicar = a => b => a * b;

const porDos = multiplicar(2);
console.log(porDos(5)); // 10
console.log(multiplicar(3)(4)); // 12

High-order functions

Una función de orden superior es cualquier función que recibe otra función como argumento o devuelve una función. map, filter y reduce son los ejemplos más conocidos.

high-order.js 
const numeros = [1, 2, 3, 4];
const pares = numeros.filter(n => n % 2 === 0);
const cuadrados = numeros.map(n => n * n);
const suma = numeros.reduce((acc, n) => acc + n, 0);

console.log(pares);      // [2, 4]
console.log(cuadrados);  // [1, 4, 9, 16]
console.log(suma);       // 10
