Closures avanzados

Un closure es la combinación de una función con su entorno léxico — básicamente, la función recuerda las variables del ámbito donde fue creada, incluso después de que ese ámbito haya terminado.

Qué es un closure

Cuando una función interna accede a variables de una función externa que ya retornó, se forma un closure. Es posible porque JavaScript mantiene viva la scope chain en memoria.

closure-basico.js 
function crearSaludo(mensaje) {
  return function (nombre) {
    console.log(`${mensaje}, ${nombre}`);
  };
}

const decirHola = crearSaludo('Hola');
decirHola('Ana'); // Hola, Ana

Closures en loops: var vs let

El clásico problema del closure en un bucle con var desaparece usando let, que crea un nuevo binding en cada iteración gracias a su scope de bloque.

loop-closure.js 
// Con var — todas imprimen 3
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}

// Con let — imprime 0, 1, 2
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}

Módulos privados con closure

Antes de los módulos ES6, los closures eran la forma estándar de crear propiedades y métodos privados.

modulo-privado.js 
function crearBanco() {
  let saldo = 0;

  return {
    depositar(monto) {
      saldo += monto;
    },
    obtenerSaldo() {
      return saldo;
    }
  };
}

const cuenta = crearBanco();
cuenta.depositar(500);
console.log(cuenta.obtenerSaldo()); // 500
console.log(cuenta.saldo);          // undefined

Memoización

Los closures permiten cachear resultados de funciones costosas: la caché vive en el closure y no es accesible desde fuera.

memoizacion.js 
function memoizar(fn) {
  const cache = new Map();
  return function (arg) {
    if (cache.has(arg)) {
      return cache.get(arg);
    }
    const resultado = fn(arg);
    cache.set(arg, resultado);
    return resultado;
  };
}

const factorial = memoizar(n =>
  n <= 1 ? 1 : n * factorial(n - 1)
);

console.log(factorial(5)); // 120 (calcula)
console.log(factorial(5)); // 120 (cache)

Cuidado con memory leaks. Los closures mantienen referencias a su ámbito exterior. Si una referencia grande (como un DOM node) queda atrapada en un closure que nunca se libera, esa memoria nunca se recolecta.
