Web APIs

El navegador expone decenas de APIs que van mucho más allá del DOM. Desde almacenar datos en el cliente hasta comunicación bidireccional en tiempo real, estas herramientas convierten a JS en un lenguaje capaz de construir aplicaciones completas.

LocalStorage y SessionStorage

Son la forma más simple de persistir datos en el navegador. Solo guardan strings, pero con JSON.stringify y JSON.parse almacenas objetos fácilmente.

storage.js 
localStorage.setItem('tema', 'oscuro');
console.log(localStorage.getItem('tema')); // "oscuro"
localStorage.removeItem('tema');
localStorage.clear();

// Objetos
const user = { nombre: 'Ana' };
localStorage.setItem('user', JSON.stringify(user));
const parsed = JSON.parse(localStorage.getItem('user'));

IndexedDB

Una base de datos NoSQL del lado del cliente para grandes volúmenes de datos estructurados. La API es asíncrona y basada en eventos, más compleja que localStorage pero mucho más potente.

indexeddb.js 
const request = indexedDB.open('MiDB', 1);

request.onupgradeneeded = (event) => {
  const db = event.target.result;
  db.createObjectStore('usuarios', { keyPath: 'id' });
};

request.onsuccess = (event) => {
  const db = event.target.result;
  const tx = db.transaction('usuarios', 'readwrite');
  tx.objectStore('usuarios').add({ id: 1, nombre: 'Ana' });
};

Geolocation API

Accede a la ubicación del dispositivo (si el usuario lo permite). Útil para mapas, check-ins o contenido contextual.

geolocation.js 
navigator.geolocation.getCurrentPosition(
  (pos) => {
    const { latitude, longitude } = pos.coords;
    console.log(`Lat: ${latitude}, Lon: ${longitude}`);
  },
  (err) => console.error(err.message)
);

WebSockets

Permiten comunicación bidireccional persistente entre el cliente y el servidor. Ideales para chats, notificaciones en tiempo real o juegos multijugador.

websocket.js 
const ws = new WebSocket('wss://ejemplo.com/chat');

ws.onopen = () => ws.send('Hola servidor');
ws.onmessage = (event) => console.log('Recibido:', event.data);
ws.onclose = () => console.log('Conexión cerrada');

Service Workers

Scripts que el navegador ejecuta en segundo plano, separados de la página. Permiten interceptar peticiones de red, cachear recursos y habilitar la experiencia offline.

sw.js 
// Registro
navigator.serviceWorker.register('/sw.js');

// sw.js
self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open('v1').then(cache =>
      cache.addAll(['/', '/index.html', '/app.js'])
    )
  );
});

self.addEventListener('fetch', (e) => {
  e.respondWith(
    caches.match(e.request)
      .then(resp => resp || fetch(e.request))
  );
});

Storage vs Cache. localStorage y IndexedDB almacenan datos de aplicación (JSON, archivos); la Cache API (usada por Service Workers) almacena respuestas HTTP. Cada uno tiene su propósito — no uses uno para lo que corresponde al otro.
