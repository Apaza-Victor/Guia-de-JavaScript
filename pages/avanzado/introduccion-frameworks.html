Introducción a frameworks

Después de dominar JavaScript vanilla, el siguiente paso natural es conocer los frameworks que dominan la industria. No se trata de aprenderlos todos, sino de entender qué problema resuelve cada uno y cuándo conviene usarlos.

Framework vs librería

Una librería es una herramienta que llamas tú cuando quieres (ej. Lodash, Day.js). Un framework define la arquitectura de tu aplicación y llama a tu código cuando lo necesita — es el principio de Inversion of Control. React suele llamarse librería, pero con su ecosistema funciona como un framework.

React

Creado por Meta, React se basa en componentes declarativos y un virtual DOM que minimiza las manipulaciones del DOM real. Usa JSX (HTML dentro de JS) y un flujo de datos unidireccional.

Componente.jsx 
function Contador() {
  const [count, setCount] = React.useState(0);

  return (
    <div>
      <p>Has hecho clic {count} veces</p>
      <button onClick={() => setCount(count + 1)}>
        Click
      </button>
    </div>
  );
}

Vue

Vue es progresivo: puedes usarlo en una página con un script CDN o construir una SPA completa con Vite. Su sintaxis template-based es intuitiva y su sistema de reactividad es automático.

App.vue 
<template>
  <div>
    <p>{{ mensaje }}</p>
    <button @click="invertir">Invertir</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';
const mensaje = ref('Hola Vue');
function invertir() {
  mensaje.value = mensaje.value.split('').reverse().join('');
}
</script>

Angular

Angular es un framework completo de Google. Incluye routing, HTTP client, formularios reactivos, inyección de dependencias y más. Usa TypeScript de forma nativa y su curva de aprendizaje es la más pronunciada.

componente.ts 
import { Component } from '@angular/core';

@Component({
  selector: 'app-saludo',
  template: '<h1>{{ mensaje }}</h1>'
})
export class SaludoComponent {
  mensaje = 'Hola Angular';
}

Alternativas modernas

Svelte y Solid son frameworks compiladores que mueven el trabajo del navegador al build step, generando JS ultra-eficiente. No usan virtual DOM y ofrecen una experiencia de desarrollo muy limpia.

svelte.svelte 
<script>
  let count = 0;
</script>

<button on:click={() => count++}>
  Clicks: {count}
</button>

Antes de elegir un framework, dominá los fundamentos. Entender el DOM, las promesas, el asincronismo y los closures te dará una base que funciona igual en React, Vue o Angular. El framework es solo la punta del iceberg.
