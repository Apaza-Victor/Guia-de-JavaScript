Introducción a TypeScript

TypeScript es JavaScript con tipos. No reemplaza a JS — lo extiende añadiendo un sistema de tipos estático que detecta errores en tiempo de compilación, antes de que lleguen a producción.

TypeScript como superset de JS

Todo código JavaScript válido es también TypeScript válido. La diferencia es que TS añade sintaxis para declarar tipos que luego el compilador (tsc) elimina, generando JS limpio. Esto significa que puedes adoptarlo de forma gradual, archivo por archivo.

hola-typescript.ts 
function saludar(nombre: string): string {
  return `Hola, ${nombre}`;
}

const mensaje = saludar('Ana');
console.log(mensaje);

Tipos básicos

TypeScript ofrece los mismos tipos que JavaScript, pero puedes declararlos explícitamente para que el compilador verifique su uso.

JSTSEjemplo
let n = 42let n: number = 42number
let s = "hola"let s: string = "hola"string
let ok = truelet ok: boolean = trueboolean
let arr = [1,2]let arr: number[] = [1,2]Array<number>
let obj = {a:1}let obj: {a: number} = {a:1}object
let x = nulllet x: null = nullnull / undefined
let valor = cualquier_cosalet valor: any = cualquier_cosaany

Interfaces y type alias

Las interfaces definen la forma de un objeto. Los type alias son más flexibles y pueden representar uniones, tuplas y tipos primitivos.

interfaces.ts 
interface Usuario {
  id: number;
  nombre: string;
  email?: string; // opcional
}

type Resultado = 'éxito' | 'error' | 'pendiente';

function procesar(u: Usuario): Resultado {
  if (u.id > 0) return 'éxito';
  return 'error';
}

Genéricos básicos

Los genéricos permiten crear funciones y tipos que funcionan con cualquier tipo, manteniendo la seguridad de tipos.

genericos.ts 
function identidad<T>(valor: T): T {
  return valor;
}

const num = identidad(42);    // tipo inferido: number
const txt = identidad('hola'); // tipo inferido: string

Configuración con tsconfig.json

El archivo tsconfig.json centraliza las opciones del compilador: versión de JS de salida, directorios de entrada/salida y nivel de estrictitud.

tsconfig.json 
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}

Preferí unknown sobre any. any desactiva completamente el sistema de tipos. unknown fuerza a que verifiques el tipo antes de usarlo, manteniendo la seguridad sin perder flexibilidad.
