BOM: window, location, history, navigator

El DOM se ocupa del contenido de la página. El BOM —Browser Object Model— abarca todo lo que rodea a la ventana del navegador: la URL, el historial, el dispositivo del usuario y los temporizadores.

El objeto global: window

window es el objeto raíz del BOM. Todo lo que declaramos con var o las funciones globales cuelgan de él. También proporciona métodos de interacción directa con el usuario.

window-metodos.js 
window.alert('Mensaje de alerta');
const respuesta = window.confirm('¿Estás seguro?'); // true/false
const nombre = window.prompt('¿Cómo te llamas?');   // string o null

window.open('https://example.com', '_blank');
window.close(); // cierra la ventana actual (con limitaciones)

console.log(window.innerWidth);  // ancho del viewport
console.log(window.innerHeight); // alto del viewport

location

window.location contiene información sobre la URL actual y permite navegar a otras páginas. Es tanto de lectura como de escritura.

Método / PropiedadQué hace
location.hrefURL completa (lectura/escritura)
location.protocolprotocolo: https:, http:
location.hostdominio + puerto: example.com:8080
location.pathnameruta: /pages/dom-y-eventos/bom.html
location.searchquery string: ?id=5&lang=es
location.hashhash: #section-2
location.assign(url)navega a una URL (deja entrada en el historial)
location.replace(url)navega sin dejar entrada en el historial
location.reload()recarga la página actual
location-ejemplos.js 
// Redirigir
window.location.href = 'https://example.com';
window.location.assign('/nueva-ruta');

// Redirigir sin que el usuario pueda volver atrás
window.location.replace('/login');

// Leer parámetros de la URL
const params = new URLSearchParams(location.search);
console.log(params.get('id')); // "5"

history

window.history permite navegar por el historial de sesión del usuario. No puedes leer las URLs del historial por seguridad, pero sí moverte entre ellas.

history.js 
window.history.back();      // retrocede una página
window.history.forward();   // avanza una página
window.history.go(-2);      // retrocede dos páginas
window.history.go(1);       // avanza una página

console.log(window.history.length); // número de entradas en el historial

navigator

window.navigator contiene información sobre el navegador y el dispositivo del usuario. Es útil para detectar capacidades, no para identificar al usuario.

navigator.js 
console.log(navigator.userAgent);      // cadena del navegador
console.log(navigator.language);       // "es-ES"
console.log(navigator.onLine);         // true/false conexión
console.log(navigator.platform);       // "Win32", "MacIntel"…

// Geolocalización (requiere permiso del usuario)
navigator.geolocation.getCurrentPosition(pos => {
  console.log(pos.coords.latitude, pos.coords.longitude);
});

Temporizadores: setTimeout y setInterval

Estos métodos permiten ejecutar código después de un tiempo o de forma repetitiva. Ambos devuelven un identificador que puedes usar para cancelarlos.

temporizadores.js 
// Una vez después de 2 segundos
const timerId = setTimeout(() => {
  console.log('Pasaron 2 segundos');
}, 2000);

clearTimeout(timerId); // lo cancelas antes de que se ejecute

// Cada 1 segundo
const intervalId = setInterval(() => {
  console.log('Tick');
}, 1000);

clearInterval(intervalId); // lo detienes

screen

window.screen proporciona información sobre la pantalla física del dispositivo, no sobre el tamaño de la ventana.

screen.js 
console.log(screen.width);       // resolución horizontal
console.log(screen.height);      // resolución vertical
console.log(screen.availWidth);  // espacio disponible (sin taskbar)
console.log(screen.colorDepth);  // profundidad de color

El BOM es la capa que conecta tu código con el entorno del navegador. A partir de aquí el siguiente salto es la programación orientada a objetos, donde organizarás todo este conocimiento en estructuras más abstractas y reutilizables.
