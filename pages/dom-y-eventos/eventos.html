Eventos

La Web es interactiva porque los elementos pueden escuchar lo que el usuario hace: clicks, teclas, envíos de formularios… Los eventos son el puente entre la acción del usuario y la lógica de JavaScript.

addEventListener

La forma estándar de suscribirse a un evento es con addEventListener. Recibe el tipo de evento, una función callback y opcionalmente un objeto de configuración (como once o capture).

add-event-listener.js 
const btn = document.querySelector('#miBoton');

btn.addEventListener('click', function () {
  console.log('¡Click!');
});

// Con arrow function
btn.addEventListener('click', () => console.log('Click!'));

// Opción once: se ejecuta una sola vez y se auto-remueve
btn.addEventListener('click', handler, { once: true });

removeEventListener

Para desuscribirte necesitas la misma referencia de función que usaste al suscribirte. Por eso no funcionan las funciones anónimas si después quieres removerlas.

remove-event-listener.js 
function handleClick() {
  console.log('Click');
}

btn.addEventListener('click', handleClick);
btn.removeEventListener('click', handleClick); // ✅ funciona

// ❌ No funciona: son funciones distintas
btn.addEventListener('click', () => {});
btn.removeEventListener('click', () => {});

El objeto event

Cuando el callback se ejecuta recibe un objeto event con información sobre lo que ocurrió. Las propiedades más útiles son target, currentTarget, type y métodos como preventDefault y stopPropagation.

objeto-event.js 
document.querySelector('a').addEventListener('click', e => {
  e.preventDefault(); // evita la navegación
  console.log(e.type);       // "click"
  console.log(e.target);     // elemento que disparó el evento
  console.log(e.currentTarget); // elemento donde está el listener
});

stopPropagation con cuidado. Llamar a e.stopPropagation() detiene el burbujeo, pero también puede romper patrones como la delegación de eventos. Úsalo solo cuando realmente necesites aislar un elemento del árbol de eventos.

Tipos de eventos comunes

Mouse

eventos-mouse.js 
elemento.addEventListener('click', handler);
elemento.addEventListener('dblclick', handler);
elemento.addEventListener('mouseenter', handler);
elemento.addEventListener('mouseleave', handler);
elemento.addEventListener('mousemove', handler);

Teclado

eventos-teclado.js 
document.addEventListener('keydown', e => {
  console.log(e.key);    // "Enter", "a", "Escape"…
  console.log(e.code);   // "Enter", "KeyA", "Escape"…
  console.log(e.ctrlKey); // true si Ctrl está presionado
});

document.addEventListener('keyup', handler);

Formularios

eventos-formulario.js 
form.addEventListener('submit', handler);
input.addEventListener('focus', handler);
input.addEventListener('blur', handler);
input.addEventListener('input', handler); // cada vez que cambia el valor
input.addEventListener('change', handler); // cuando pierde el foco si cambió

Burbujeo y captura

Cuando disparas un evento en un elemento, este no se queda ahí. Primero recorre el árbol desde la raíz hasta el elemento (fase de captura), luego desde el elemento hasta la raíz (fase de burbujeo). Por defecto los listeners escuchan en fase de burbujeo.

burbujeo.html 
<div id="padre">
  <button id="hijo">Haz clic</button>
</div>
burbujeo.js 
document.querySelector('#padre').addEventListener('click', () => {
  console.log('padre (burbujeo)');
});

document.querySelector('#hijo').addEventListener('click', e => {
  console.log('hijo');
  // e.stopPropagation(); // descomenta para evitar que llegue al padre
});

// Para escuchar en captura, pasa { capture: true }
document.querySelector('#padre').addEventListener('click', () => {
  console.log('padre (captura)');
}, { capture: true });

Entender el flujo de eventos es clave para dominar la delegación, que veremos a continuación.
