Manipulación del DOM

Saber seleccionar elementos es el primer paso. El verdadero poder llega cuando creas, modificas y eliminas nodos del árbol. Aquí es donde una página estática se convierte en una interfaz dinámica.

innerHTML vs textContent

La forma más directa de cambiar el contenido de un elemento es con innerHTML o textContent. La diferencia es fundamental: innerHTML interpreta el string como HTML, mientras que textContent lo trata como texto plano.

inner-vs-text.js 
const div = document.querySelector('#output');

div.textContent = '<strong>Hola</strong>';
// Muestra: <strong>Hola</strong> (literal)

div.innerHTML = '<strong>Hola</strong>';
// Muestra: Hola (en negrita)

Peligro de XSS: nunca uses innerHTML con datos que vengan del usuario, una API o cualquier fuente externa sin sanitizarlos primero. Un string como <img src=x onerror="alert('XSS')"> ejecutaría código malicioso. Prefiere textContent cuando solo necesites texto.

createElement y appendChild

Para crear elementos desde cero usa document.createElement. Una vez creado lo insertas con appendChild o con el método más flexible append, que acepta varios nodos y strings.

crear-elemento.js 
const li = document.createElement('li');
li.textContent = 'Item nuevo';

const lista = document.querySelector('ul');
lista.appendChild(li);

// append permite varios argumentos
lista.append('texto suelto', document.createElement('span'));

insertBefore

Si necesitas insertar un elemento en una posición específica —no al final— usa insertBefore. Recibe el nodo a insertar y el nodo de referencia.

insert-before.js 
const lista = document.querySelector('ul');
const primero = lista.firstElementChild;

const nuevo = document.createElement('li');
nuevo.textContent = 'Al inicio';

lista.insertBefore(nuevo, primero);

Eliminar elementos

Puedes eliminar un nodo con removeChild (desde el padre) o con el método directo remove, más moderno y legible.

eliminar-nodos.js 
const item = document.querySelector('.item');

// Forma antigua
item.parentElement.removeChild(item);

// Forma moderna
item.remove();

classList: add, remove, toggle

Para manipular clases CSS de forma limpia usa la propiedad classList. Es mucho más cómoda que jugar con className.

classlist.js 
const el = document.querySelector('.card');

el.classList.add('active');          // añade una clase
el.classList.remove('hidden');       // quita una clase
el.classList.toggle('visible');      // si existe la quita, si no la añade
el.classList.contains('active');     // true / false
el.classList.replace('old', 'new');  // reemplaza una clase por otra

setAttribute y style

Para modificar atributos HTML o estilos en línea tienes setAttribute y la propiedad style.

atributos-y-estilos.js 
const img = document.querySelector('img');
img.setAttribute('alt', 'Descripción');
img.setAttribute('src', 'nueva-imagen.jpg');

const caja = document.querySelector('.caja');
caja.style.backgroundColor = '#ff5722';
caja.style.borderRadius = '8px';

// Para leer estilos computados usa getComputedStyle
const estilos = getComputedStyle(caja);
console.log(estilos.backgroundColor);

Con estas herramientas ya puedes construir una interfaz que reaccione a datos y a interacciones del usuario. En el próximo tema verás cómo capturar esas interacciones con eventos.
