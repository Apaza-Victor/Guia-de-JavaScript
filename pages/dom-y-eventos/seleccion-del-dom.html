El DOM: selección de elementos

Para que JavaScript pueda modificar una página primero necesita encontrar los elementos correctos. El navegador expone el documento como un árbol de nodos, y con unos pocos métodos puedes obtener cualquier etiqueta, clase o selector que necesites.

¿Qué es el DOM?

DOM son las siglas de Document Object Model. Cuando el navegador carga una página HTML convierte cada etiqueta en un objeto (un nodo) y los organiza en un árbol. JavaScript puede recorrer y modificar ese árbol en tiempo real gracias al objeto global document.

dom-tree.html 
<html>
  <body>
    <header id="top">
      <h1 class="title">Hola</h1>
    </header>
  </body>
</html>

En este ejemplo, document apunta al nodo raíz; document.body al <body>; document.getElementById('top') devuelve el <header>; y document.querySelector('.title') el <h1>.

getElementById

Es el método más rápido para seleccionar un elemento, pero solo funciona con id. Recibe el identificador sin la # y devuelve el elemento o null si no existe.

get-element-by-id.js 
const header = document.getElementById('top');
console.log(header); // <header id="top">…</header>

const inexistente = document.getElementById('foo');
console.log(inexistente); // null

querySelector y querySelectorAll

Son los métodos más flexibles porque aceptan cualquier selector CSS. querySelector devuelve el primer elemento que coincida; querySelectorAll devuelve todos los que coincidan en una NodeList estática.

query-selector.js 
// Primer <h1> del documento
const titulo = document.querySelector('h1');

// Todos los elementos con clase "item"
const items = document.querySelectorAll('.item');

// Primer <li> dentro de un <ul class="list">
const primerLi = document.querySelector('ul.list li');

// Atributo data
const modal = document.querySelector('[data-modal="main"]');

querySelector es tu navaja suiza. Si solo necesitas un elemento y puedes expresarlo con un selector CSS, este método es la opción más legible. Reserva getElementById solo cuando la velocidad sea crítica (bucles muy grandes o animaciones de 60 fps).

Otros métodos de selección

getElementsByClassName y getElementsByTagName devuelven una HTMLCollection viva, lo que significa que se actualiza automáticamente si el DOM cambia. Aunque existen, querySelectorAll suele ser más predecible porque su colección es estática.

html-collection-vs-nodelist.js 
const viva = document.getElementsByClassName('item');
const estatica = document.querySelectorAll('.item');

console.log(viva.length);   // 3
console.log(estatica.length); // 3

document.body.append(document.createElement('div'));

// La colección viva ahora tiene 4 elementos (se actualizó sola)
console.log(viva.length);   // 4
console.log(estatica.length); // 3

Navegación por el árbol

Una vez que tienes un elemento puedes moverte a sus nodos vecinos: parentElement, children, nextElementSibling, previousElementSibling, firstElementChild y lastElementChild.

navegacion-dom.js 
const item = document.querySelector('.item');

console.log(item.parentElement);       // <ul>
console.log(item.children);            // HTMLCollection de hijos
console.log(item.nextElementSibling);  // siguiente hermano
console.log(item.previousElementSibling); // hermano anterior

Estas propiedades son de solo lectura. Para modificar el árbol necesitarás los métodos de manipulación que veremos en el siguiente tema.
