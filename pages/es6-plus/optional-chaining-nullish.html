Optional chaining (?.) y Nullish coalescing (??)

Dos operadores modernos que trabajan juntos para acceder propiedades profundas y asignar valores por defecto de forma segura, eliminando los tediosos && encadenados y las confusiones con valores falsy.

Optional chaining — ?.

El optional chaining permite leer propiedades encadenadas sin verificar manualmente que cada nivel exista. Si en cualquier punto de la cadena el valor es null o undefined, la expresión cortocircuita y devuelve undefined.

optional-chaining.js 
const usuario = {
  perfil: {
    nombre: 'Ana'
  }
};

// Sin optional chaining — tedioso y verboso
const ciudad = usuario.direccion && usuario.direccion.ciudad;

// Con optional chaining — limpio y seguro
const ciudad2 = usuario.direccion?.ciudad;
console.log(ciudad2); // undefined

El operador también funciona para llamar métodos que pueden no existir y para acceder a índices de arrays de forma segura.

metodos-y-arrays.js 
// Método opcional
const resultado = usuario.saludar?.(); // undefined si no existe

// Índice opcional
const items = null;
console.log(items?.[0]); // undefined

Nullish coalescing — ??

El operador ?? devuelve el operando del lado derecho solo cuando el izquierdo es null o undefined. A diferencia de ||, no trata otros valores falsy como 0, "" (cadena vacía) o false como "ausencia de valor".

nullish-vs-or.js 
const puntuacion = 0;
const nombre = '';

console.log(puntuacion || 100);  // 100  ← 0 es falsy, lo reemplaza
console.log(puntuacion ?? 100);  // 0    ← 0 no es null/undefined

console.log(nombre || 'Invitado'); // 'Invitado' ← "" es falsy
console.log(nombre ?? 'Invitado'); // ''          ← "" no es null/undefined
OperadorReacciona anteEjemplo con 0
|| (OR lógico)cualquier falsy (0, "", false, null, undefined, NaN)0 || 100 → 100
?? (Nullish)solo null / undefined0 ?? 100 → 0

No mezcles ?? con || ni && sin paréntesis explícitos. JavaScript lo prohíbe por ambigüedad. Si necesitas combinarlos, usa paréntesis: (a ?? b) || c.

Trabajando juntos

El patrón más potente es combinar ambos operadores: accede a una propiedad profunda con ?. y proporciona un valor por defecto con ??.

combinacion.js 
function obtenerPais(usuario) {
  return usuario?.direccion?.pais ?? 'Desconocido';
}

console.log(obtenerPais({ direccion: { pais: 'Chile' } })); // 'Chile'
console.log(obtenerPais({}));                                // 'Desconocido'

Este patrón es especialmente útil al trabajar con datos de API donde la estructura puede ser impredecible o cuando encadenas accesos a objetos que pueden no estar inicializados.
