Proxy y Reflect

Proxy te permite interceptar y personalizar operaciones fundamentales sobre objetos (lectura, escritura, llamadas a funciones, etc.). Reflect proporciona los comportamientos por defecto para esas mismas operaciones, funcionando como la contraparte "normal" de los traps de Proxy.

Qué es un Proxy

Un Proxy envuelve un objeto target y te permite definir traps (funciones manejadoras) que se ejecutan cuando se realizan ciertas operaciones sobre él. No modificas el objeto original, sino que interceptas el acceso a través del proxy.

proxy-basico.js 
const target = { mensaje: 'hola' };

const proxy = new Proxy(target, {
  get(objeto, propiedad) {
    console.log(`Leyendo "${propiedad}"`);
    return objeto[propiedad];
  }
});

console.log(proxy.mensaje);
// Leyendo "mensaje"
// "hola"

Reflect: el default de cada trap

Reflect exporta métodos estáticos con el comportamiento por defecto de las operaciones del lenguaje. En lugar de hacer objeto[prop] dentro de un trap, usamos Reflect.get(objeto, prop) — más seguro y predecible.

reflect-como-default.js 
const proxy = new Proxy(target, {
  get(objeto, propiedad, receptor) {
    console.log(`Acceso a: ${propiedad}`);
    return Reflect.get(objeto, propiedad, receptor);
  }
});

Validación con set

Un uso clásico de Proxy es validar datos antes de asignarlos a un objeto. El trap set puede rechazar la asignación devolviendo false (o lanzando un error).

validacion.js 
const usuario = new Proxy({}, {
  set(objeto, propiedad, valor, receptor) {
    if (propiedad === 'edad' && (typeof valor !== 'number' || valor < 0)) {
      throw new Error('La edad debe ser un número positivo');
    }
    return Reflect.set(objeto, propiedad, valor, receptor);
  }
});

usuario.edad = 25;  // ✅
console.log(usuario.edad); // 25
// usuario.edad = -5; // ❌ Error

Logging automático

Proxy permite añadir logging a todas las operaciones de un objeto sin modificar su código interno — ideal para debugging o auditoría.

logging.js 
function crearLogger(target) {
  return new Proxy(target, {
    get(objeto, prop, receptor) {
      console.log(`[GET] ${String(prop)}`);
      return Reflect.get(objeto, prop, receptor);
    },
    set(objeto, prop, valor, receptor) {
      console.log(`[SET] ${String(prop)} = ${valor}`);
      return Reflect.set(objeto, prop, valor, receptor);
    }
  });
}

const datos = crearLogger({ nombre: 'Ana' });
datos.nombre;       // [GET] nombre
datos.edad = 30;    // [SET] edad = 30

Caché con Proxy

Puedes usar Proxy para cachear resultados de funciones computacionalmente costosas.

cache.js 
function crearCache(fn) {
  const cache = new Map();
  return new Proxy(fn, {
    apply(target, thisArg, args) {
      const clave = JSON.stringify(args);
      if (cache.has(clave)) {
        console.log('Cache hit');
        return cache.get(clave);
      }
      const resultado = Reflect.apply(target, thisArg, args);
      cache.set(clave, resultado);
      return resultado;
    }
  });
}

const fib = crearCache((n) => n <= 1 ? n : fib(n - 1) + fib(n - 2));
console.log(fib(10)); // 55 (calcula)
console.log(fib(10)); // 55 (cache hit)

Proxy con construct (interceptar new)

El trap construct intercepta llamadas con new, permitiendo controlar la creación de instancias.

construct.js 
function Usuario(nombre) {
  this.nombre = nombre;
}

const ProxyUsuario = new Proxy(Usuario, {
  construct(target, args, newTarget) {
    console.log(`Creando usuario: ${args[0]}`);
    const instancia = Reflect.construct(target, args, newTarget);
    instancia.creadoEn = new Date();
    return instancia;
  }
});

const u = new ProxyUsuario('Ana');
// Creando usuario: Ana
console.log(u.nombre);    // "Ana"
console.log(u.creadoEn);  // fecha actual

No abuses de Proxy. Cada operación interceptada añade overhead de rendimiento. Para validación de esquemas considera bibliotecas como Zod o Yup; para observabilidad usa herramientas específicas. Proxy es más lento que el acceso directo a propiedades, así que úsalo solo cuando necesites su poder de intercepción.
