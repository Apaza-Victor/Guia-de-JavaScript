Generadores e iteradores

Los generadores son funciones que pueden pausar su ejecución y reanudarla después, manteniendo su estado interno. Combinados con el protocolo de iteración, permiten trabajar con secuencias de datos bajo demanda de forma elegante.

El protocolo de iteración

Un objeto es iterable si implementa el método Symbol.iterator, que devuelve un iterador (un objeto con un método next() que a su vez devuelve { value, done }). Arrays, Strings, Maps y Sets son iterables nativos.

protocolo-iteracion.js 
const iterador = [10, 20, 30][Symbol.iterator]();

console.log(iterador.next()); // { value: 10, done: false }
console.log(iterador.next()); // { value: 20, done: false }
console.log(iterador.next()); // { value: 30, done: false }
console.log(iterador.next()); // { value: undefined, done: true }

function* y yield

Un generador se declara con function*. La palabra clave yield pausa la ejecución y devuelve un valor. Cada llamada a .next() reanuda la función hasta el siguiente yield.

generador-basico.js 
function* contador() {
  yield 1;
  yield 2;
  yield 3;
}

const gen = contador();
console.log(gen.next()); // { value: 1, done: false }
console.log(gen.next()); // { value: 2, done: false }
console.log(gen.next()); // { value: 3, done: false }
console.log(gen.next()); // { value: undefined, done: true }

Iterar sobre un generador

Los generadores son iterables, así que puedes usar for...of directamente en lugar de llamar manualmente a .next().

for-of-generador.js 
function* tresSaludos() {
  yield 'hola';
  yield 'mundo';
  yield '!';
}

for (const palabra of tresSaludos()) {
  console.log(palabra);
}
// "hola"  "mundo"  "!"

Generadores infinitos y lazy evaluation

Como los generadores producen valores bajo demanda, puedes modelar secuencias infinitas sin consumir memoria.

ids-infinitos.js 
function* generarId() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const ids = generarId();
console.log(ids.next().value); // 1
console.log(ids.next().value); // 2
console.log(ids.next().value); // 3
// Sigue indefinidamente sin llenar la memoria

Delegar generadores con yield*

yield* delega la iteración a otro generador o a cualquier iterable, como si sus valores se produjeran en el generador actual.

yield-star.js 
function* numeros() {
  yield 1;
  yield 2;
}

function* letras() {
  yield 'a';
  yield 'b';
}

function* combinado() {
  yield* numeros();
  yield* letras();
  yield* [100, 200]; // también funciona con arrays
}

console.log([...combinado()]); // [1, 2, 'a', 'b', 100, 200]

¿Cuándo usar generadores? Son ideales para secuencias perezosas, colas de tareas, generación de IDs únicos, procesamiento de grandes volúmenes de datos (streaming) y cualquier situación donde necesites pausar/reanudar un flujo de trabajo.

Pasar valores a next()

Puedes enviar valores al generador pasándolos como argumento a .next(valor). El valor recibido reemplaza la expresión yield que pausó la ejecución.

next-con-valor.js 
function* conversacion() {
  const a = yield '¿cómo estás?';
  const b = yield 'me alegra que digas ' + a;
  yield 'adiós ' + b;
}

const gen = conversacion();
console.log(gen.next().value);         // ¿cómo estás?
console.log(gen.next('bien').value);   // me alegra que digas bien
console.log(gen.next('amigo').value);  // adiós amigo
