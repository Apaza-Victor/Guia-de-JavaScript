Módulos: import / export

Desde ES6, JavaScript tiene un sistema de módulos nativo que permite dividir el código en archivos independientes. Con export e import puedes compartir y consumir funcionalidad entre archivos sin contaminar el ámbito global.

¿Por qué módulos?

Antes de ES6 todo el código JS compartía el mismo scope global. Si dos archivos declaraban una variable con el mismo nombre, la segunda sobrescribía a la primera. Los módulos resuelven esto aislando cada archivo en su propio ámbito: todo lo definido dentro de un módulo es privado a menos que se exponga con export.

Named exports

Puedes exportar múltiples valores con nombre desde un mismo archivo usando la palabra clave export delante de la declaración o al final con una sentencia export { }.

matematicas.js 
export const PI = 3.1416;

export function sumar(a, b) {
  return a + b;
}

function restar(a, b) {
  return a - b;
}

export { restar };
app.js 
import { PI, sumar, restar } from './matematicas.js';

console.log(sumar(5, 3));   // 8
console.log(PI);            // 3.1416

Default export

Cada módulo puede tener un único export default, que se importa sin llaves y puede recibir cualquier nombre en el importador.

saludo.js 
export default function saludar(nombre) {
  return `¡Hola, ${nombre}!`;
}
app.js 
import saludar from './saludo.js';

console.log(saludar('Ana')); // ¡Hola, Ana!

Default vs named: usa export default cuando el módulo exporta una única funcionalidad principal (una clase, una función). Usa named exports cuando exportas varias utilidades relacionadas. En la práctica muchos proyectos combinan ambos.

Renombrar imports y exports

Tanto en la exportación como en la importación puedes usar as para cambiar el nombre de un valor.

renombrar.js 
// Renombrar al exportar
function obtenerUsuario() { /* ... */ }
export { obtenerUsuario as getUser };

// Renombrar al importar
import { getUser as traerUsuario } from './renombrar.js';

Importar todo (namespace)

El patrón import * as agrupa todas las exportaciones de un módulo en un solo objeto.

app.js 
import * as Mat from './matematicas.js';

console.log(Mat.PI);          // 3.1416
console.log(Mat.sumar(2, 3)); // 5

Módulos en el navegador

Para usar módulos en el navegador debes incluir el atributo type="module" en la etiqueta <script>. Los módulos se ejecutan en modo estricto y con carga diferida (defer por defecto).

index.html 
<script type="module" src="app.js"></script>

Los módulos requieren un servidor HTTP — file:// no funciona por restricciones CORS. Usa python3 -m http.server o cualquier servidor local.

Re-exportaciones (barrel files)

Puedes re-exportar valores de otros módulos para crear archivos "barril" que agrupen múltiples fuentes en un único punto de entrada.

index.js 
export { sumar, restar } from './matematicas.js';
export { default as saludar } from './saludo.js';
