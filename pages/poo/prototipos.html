Prototipos y herencia prototípica

JavaScript no tiene clases clásicas. En lugar de eso, los objetos heredan de otros objetos a través de una cadena de prototipos. Este mecanismo es la base de todo en el lenguaje, incluido el sistema de objetos que usas a diario.

¿Qué es un prototipo?

Un prototipo es simplemente un objeto del que otro objeto hereda propiedades y métodos. Cuando accedes a una propiedad que no existe en el objeto, JavaScript la busca hacia arriba en la cadena de prototipos hasta encontrarla o llegar al final (null).

cadena-de-prototipos.js 
const objeto = {};
console.log(objeto.toString()); // "[object Object]"

// toString no está en objeto, pero está en Object.prototype
console.log(Object.prototype.hasOwnProperty("toString")); // true

[[Prototype]] y __proto__

Cada objeto tiene un enlace interno llamado [[Prototype]] (accesible vía __proto__ en la práctica, aunque es una propiedad obsoleta a favor de Object.getPrototypeOf).

proto.js 
const padre = { apellido: "García" };
const hijo = { nombre: "Ana" };

hijo.__proto__ = padre; // establecer prototipo (no recomendado)

console.log(hijo.nombre);  // "Ana"
console.log(hijo.apellido); // "García" — heredado

// Forma moderna:
Object.setPrototypeOf(hijo, padre);

La propiedad prototype de las funciones

Las funciones constructoras tienen una propiedad prototype que se asigna como prototipo de los objetos creados con new. No confundir con el [[Prototype]] interno de la función.

function-prototype.js 
function Persona(nombre) {
  this.nombre = nombre;
}

Persona.prototype.saludar = function () {
  console.log(`Hola, soy ${this.nombre}`);
};

const ana = new Persona("Ana");
ana.saludar(); // "Hola, soy Ana"

console.log(ana.__proto__ === Persona.prototype); // true

Object.create

Crea un objeto nuevo con el prototipo que elijas. Es la forma más directa de herencia prototípica.

object-create.js 
const animal = {
  respirar() {
    console.log("respirando...");
  }
};

const perro = Object.create(animal);
perro.ladrar = function () {
  console.log("guau!");
};

perro.respirar(); // "respirando..." — heredado
perro.ladrar();    // "guau!"

hasOwnProperty

Para saber si una propiedad es propia del objeto (no heredada) usa hasOwnProperty o, mejor, Object.hasOwn (ES2022).

has-own.js 
const obj = { a: 1 };
console.log(obj.hasOwnProperty("a"));            // true
console.log(obj.hasOwnProperty("toString"));     // false

// ES2022+
console.log(Object.hasOwn(obj, "a"));            // true

__proto__ vs prototype: __proto__ es el prototipo interno ([[Prototype]]) de un objeto; prototype es una propiedad que solo tienen las funciones (constructoras) y que se asignará como __proto__ a los objetos que creen con new.
