Encapsulamiento

El encapsulamiento protege los datos internos de un objeto para que solo se acceda a ellos de forma controlada. JavaScript fue durante años un lenguaje sin privacidad real, pero desde ES2019 tenemos campos privados con #.

Campos privados con #

Los campos privados se declaran con el prefijo # y solo son accesibles dentro de la clase. Si intentas leerlos desde fuera obtienes un error de sintaxis.

campos-privados.js 
class CuentaBancaria {
  #saldo;

  constructor(titular, saldoInicial) {
    this.titular = titular;
    this.#saldo = saldoInicial;
  }

  verSaldo() {
    return `$${this.#saldo}`;
  }

  depositar(monto) {
    if (monto > 0) this.#saldo += monto;
  }
}

const cuenta = new CuentaBancaria("Ana", 1000);
console.log(cuenta.verSaldo()); // "$1000"
// console.log(cuenta.#saldo); ❌ SyntaxError

Getters y setters

Las palabras clave get y set permiten definir propiedades que se leen y escriben como si fueran propiedades normales, pero ejecutan lógica por dentro.

getters-setters.js 
class Usuario {
  #nombre;

  constructor(nombre) {
    this.#nombre = nombre;
  }

  get nombre() {
    return this.#nombre;
  }

  set nombre(valor) {
    if (!valor || valor.length < 2) {
      console.error("Nombre inválido");
      return;
    }
    this.#nombre = valor;
  }
}

const u = new Usuario("María");
console.log(u.nombre); // "María" (getter)
u.nombre = "Lu";       // setter
console.log(u.nombre); // "Lu"
u.nombre = "A";        // "Nombre inválido"

Métodos privados

También puedes tener métodos privados con #. Solo la clase puede llamarlos internamente.

metodos-privados.js 
class Autenticacion {
  #token;

  constructor(token) {
    this.#token = token;
  }

  #validarToken() {
    return this.#token.length > 10;
  }

  acceder() {
    if (this.#validarToken()) {
      console.log("Acceso concedido");
    } else {
      console.log("Token inválido");
    }
  }
}

const auth = new Autenticacion("abc123def");
auth.acceder();      // "Acceso concedido"
// auth.#validarToken(); ❌ SyntaxError

Encapsulamiento con closures (antes de #)

Antes de los campos privados, la forma de encapsular era mediante closures usando funciones constructoras o módulos.

closure-encapsulamiento.js 
function crearContador() {
  let count = 0; // privado por closure

  return {
    incrementar() { count++; },
    decrementar() { count--; },
    obtenerValor() { return count; }
  };
}

const c = crearContador();
c.incrementar();
c.incrementar();
console.log(c.obtenerValor()); // 2
console.log(c.count);          // undefined

¿Cuándo usar campos privados? Siempre que una propiedad sea un detalle interno de implementación: saldos, tokens, configuraciones que el usuario de la clase no debería tocar. Los getters/setters son ideales para validar o transformar datos en el punto de acceso.
