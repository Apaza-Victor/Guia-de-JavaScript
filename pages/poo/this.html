Objetos y this

this es una de las palabras más escurridizas de JavaScript. No se asigna en la declaración sino cuando se invoca, y su valor cambia según cómo y dónde se llame a la función. Entenderlo es entender el 90 % de los bugs con objetos.

¿Qué es this?

this es una referencia al objeto que "ejecuta" la función actual. A diferencia de otros lenguajes donde apunta siempre a la instancia de una clase, en JS puede referirse a distintos objetos según el contexto de llamada.

this en contexto global

En el ámbito global (fuera de cualquier función), this apunta al objeto global: window en navegadores, global en Node.js.

global-this.js 
console.log(this === window); // true (en el navegador)

var color = "azul";
console.log(window.color); // "azul"

this en un método de objeto

Cuando una función se llama como método de un objeto, this apunta a ese objeto. Es el caso más intuitivo y el que se parece a otros lenguajes.

metodo-objeto.js 
const usuario = {
  nombre: "María",
  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
};

usuario.saludar(); // "Hola, soy María"

this en función regular

Si llamas a una función de manera suelta —sin que sea método de un objeto— this apunta al objeto global en modo no estricto, y es undefined en modo estricto.

funcion-suelta.js 
"use strict";

function mostrarThis() {
  console.log(this);
}

mostrarThis(); // undefined (modo estricto)

Perder el contexto es el error más común con this. Pasa cuando extraes un método de su objeto y lo asignas a una variable: const fn = usuario.saludar; fn(); — ahí this ya no es usuario.

this en arrow functions

Las funciones flecha no tienen su propio this. En su lugar heredan el this del ámbito (scope) que las envuelve. Por eso son ideales para callbacks dentro de métodos.

arrow-this.js 
const contador = {
  items: [],
  agregar(item) {
    // this aquí es contador
    setTimeout(() => {
      // this aquí también es contador (heredado)
      this.items.push(item);
      console.log(this.items);
    }, 100);
  }
};

contador.agregar("🍎");

Regla de oro: usa function cuando quieras que this dependa de cómo se llama la función. Usa arrow function cuando quieras que this sea el del entorno que la rodea — por ejemplo, dentro de un método que tiene un callback.

this en event listeners

En un event listener tradicional, this apunta al elemento que disparó el evento. Con arrow function se hereda el contexto exterior.

event-this.js 
boton.addEventListener("click", function () {
  console.log(this); // el botón
});

boton.addEventListener("click", () => {
  console.log(this); // window (o el contexto padre)
});

bind, call y apply

Estos tres métodos permiten forzar el valor de this. bind devuelve una nueva función con el contexto atado; call y apply invocan la función inmediatamente.

bind-call-apply.js 
const persona = { nombre: "Luis" };

function presentar(ciudad) {
  console.log(`${this.nombre} vive en ${ciudad}`);
}

presentar.call(persona, "Madrid");   // "Luis vive en Madrid"
presentar.apply(persona, ["Lima"]); // "Luis vive en Lima"

const bound = presentar.bind(persona);
bound("Bogotá"); // "Luis vive en Bogotá"
