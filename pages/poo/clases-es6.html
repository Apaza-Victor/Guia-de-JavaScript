Clases ES6

La palabra clave class llegó con ES6 para ofrecer una sintaxis más clara y familiar para crear objetos y manejar herencia. Pero debajo del capó sigue siendo el mismo sistema de prototipos que ya conoces.

class y constructor

Una clase se declara con class y contiene un método especial constructor que se ejecuta al crear una instancia con new.

class-basica.js 
class Persona {
  constructor(nombre, edad) {
    this.nombre = nombre;
    this.edad = edad;
  }

  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
}

const ana = new Persona("Ana", 28);
ana.saludar(); // "Hola, soy Ana"

Métodos de instancia y estáticos

Los métodos definidos dentro de la clase van al prototype. Los métodos con static se llaman directamente sobre la clase, no sobre las instancias.

metodos-estaticos.js 
class Calculadora {
  static sumar(a, b) {
    return a + b;
  }

  multiplicar(a, b) {
    return a * b;
  }
}

console.log(Calculadora.sumar(2, 3)); // 5

const calc = new Calculadora();
console.log(calc.multiplicar(2, 3));  // 6
// calc.sumar(2, 3); ❌ TypeError

Herencia con extends y super

extends establece la herencia entre clases. Dentro del constructor hijo debes llamar a super() antes de usar this.

extends-super.js 
class Animal {
  constructor(nombre) {
    this.nombre = nombre;
  }

  respirar() {
    console.log(`${this.nombre} está respirando`);
  }
}

class Perro extends Animal {
  constructor(nombre, raza) {
    super(nombre);
    this.raza = raza;
  }

  ladrar() {
    console.log("guau!");
  }
}

const firulais = new Perro("Firulais", "Labrador");
firulais.respirar(); // "Firulais está respirando"
firulais.ladrar();    // "guau!"

instanceof

El operador instanceof verifica si un objeto es instancia de una clase (recorriendo la cadena de prototipos).

instanceof.js 
console.log(firulais instanceof Perro);  // true
console.log(firulais instanceof Animal); // true
console.log(firulais instanceof Object); // true

Las clases siguen siendo prototipos. class es azúcar sintáctico. Si haces typeof Persona obtienes "function", y los métodos viven en Persona.prototype. No existe un sistema de clases como en Java o C++.
